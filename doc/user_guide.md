# 利用者のインストール・使い方

## 必要なもの

1. Windows PC、iPhoneまたはAndroidスマホ。
2. PCとスマホの両方で使う、同じGoogleアカウント。
3. 初回導入・同期用のインターネット接続。
4. 配布者から受け取ったアプリのURL。Windowsではsetup.exeも利用できます。

Google Cloud、Supabase、GitHubの登録や設定は利用者には不要です。

## PC

1. 配布者から受け取った `kotoba-memo-setup.exe` を開きます。
2. 画面の案内に従ってインストールします。
3. デスクトップの「ことばメモ」を開きます。いつものブラウザでアプリが開きます。
4. 「Googleでログイン」を押し、使うGoogleアカウントを選びます。
5. 同期用データへのアクセスを許可します。
6. 「同期済み」を確認します。

setup.exeはブラウザで開く入口を作ります。アプリ専用のウィンドウが必要な場合は、Edge／Chromeのアプリのインストール機能も利用できます。ブラウザを変えると端末内の保存場所も変わるので、ふだん使うブラウザをそろえてください。

## スマホ

1. 配布者のURLをiPhoneではSafari、AndroidではChromeで開きます。
2. ホーム画面へ追加します。ブラウザのまま使うこともできます。
3. 利用する画面で「Googleでログイン」を押します。
4. PCと同じGoogleアカウントを選び、同期用データへのアクセスを許可します。
5. 「同期済み」を確認します。

## 同期できるか確かめる

1. PCでカテゴリを作り、「同期確認」というメモを保存します。
2. スマホで同じアカウントを選びます。画面を開き直すか「同期を再確認」を押します。
3. 「同期確認」が表示されることを確認します。
4. スマホで説明を「スマホから更新」に変更します。
5. PCで画面を開き直し、変更が表示されることを確認します。
6. PC/Linux用で画像と説明を登録し、もう一方でも同じ画像と説明が表示されるか確かめます。
7. テスト用メモを削除し、もう一方からも消えることを確認します。

「同期済み」の表示だけでは不十分です。もう一方の端末で内容を確かめてください。

## 通信できないとき・接続期限が切れたとき

以前ログインした人の保存データは開けます。変更は端末に残ります。通信を戻し、「Googleに再接続」が表示された場合は押します。その後「同期を再確認」で未送信がなくなることを確認します。

未送信がある状態でブラウザのサイトデータを削除しないでください。重要なメモは「設定」→「バックアップ」でファイルへ保存してください。

## 元のことばメモから移す

1. 元アプリで「設定」→「バックアップ」を押します。
2. Google版でGoogleへログインします。
3. 「設定」→「バックアップを戻す」で、保存したJSONファイルを選びます。
4. 現在のデータを置き換える確認画面で内容を確認します。
5. もう一方の端末でも表示を確かめます。

元アプリのSupabaseデータを自動的に読み取ることはありません。元アプリはそのまま利用できます。
