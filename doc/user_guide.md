# PC・スマホで使う

## 初めて使う前に

[Google Cloud設置手順](distributor_setup.md)で、ご自身のGoogle Cloudにことばメモを設置します。PC用のセットアップと、自分のアプリURLを用意してください。Cloudの設定は最初に必要です。

旧版を使っている場合は、旧版の「設定 → バックアップ」でJSONファイルを保存します。新しいGoogleプロジェクトのアプリは、旧版のDrive専用領域を直接読むことができません。新しいアプリへログインし、JSONバックアップを戻してください。

## PC

1. `kotoba-memo-setup.exe`を実行してインストールします。
2. ことばメモを開き、自分のアプリURLを貼り付けます。
3. 「接続を確認」を押します。
4. 「Googleでログイン」を押し、開いたブラウザで自分のGoogleアカウントを選びます。
5. ログインできたらことばメモのPC画面へ戻ります。
6. 表示されたメールアドレス・接続先を確認し、「このアカウントで開始」を押します。

Windowsの署名・配布状況は提供元へ確認してください。セットアップは通常のブラウザの履歴・メモ保存領域を利用しません。ただし、Googleログイン時の外部ブラウザには以前のアカウントが出る場合があります。必ず自分のアカウントを選んでください。

## スマホ

1. PCの「設定 → スマホでも使う」にあるQRコードをカメラで読みます。URLをコピーしてスマホへ渡すこともできます。
2. 同じGoogleアカウントでログインします。
3. 表示されたメールアドレスを確認し、「このアカウントで開始」を押します。
4. 必要に応じてブラウザのメニューからホーム画面へ追加します。

スマホにsetup.exeは使いません。クライアントIDの入力も不要です。アプリを開き直すときも、アカウントを確認してからメモを表示します。

## 保存と同期

メモ・画像・カテゴリは、このアカウントのGoogle Driveのアプリ専用領域に保存されます。通常のDriveファイル一覧には表示されません。設定画面のバックアップで取り出せます。

表示中は約30秒ごと、保存時、画面へ戻ったときなどに同期を確認します。「送信待ち」がある間は端末にも変更が残っています。Googleログインの期限や権限が切れた場合は再接続してください。オフライン状態で初めて起動して利用を開始することは保証していません。

同じメモを複数端末で変更すると、検出できた競合について内容を選びます。先にバックアップしてください。完全同時送信の制限は[同期仕様](sync_design.md)を確認してください。

## ログアウト・アカウント変更

「別の人でログイン」を押すとログアウト確認が出ます。この端末のキャッシュと未送信データを削除するため、必要な場合は先に「設定 → バックアップ」を行ってください。Google Driveへ送信済みのメモは削除しません。

その後「Googleでログイン」を押して別のアカウントを選びます。別アカウントのメモは分離されます。

## PCの接続先を変更

画面の「接続先を変更」を押します。先に必要なデータをバックアップしてください。確認後に端末のログイン状態・保存データを削除し、新しいURLの入力画面を開きます。別のGoogleプロジェクトへの移行では、バックアップの復元が必要です。

## バックアップ

「設定 → バックアップ」でメモとカテゴリをJSONファイルへ保存します。「バックアップを戻す」は現在の内容を置き換えます。画像を含むため大きなファイルになる場合があります。保存場所を覚えておいてください。
