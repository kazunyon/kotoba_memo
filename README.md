# ことばメモ（利用者自身のGoogle Cloud・Google Drive版）

ことばメモは、メモや画像付きの手順を保存するアプリです。カテゴリ分け・読み上げ・バックアップもできます。PCとスマホで、同じGoogleアカウントを使います。

メモは、そのGoogleアカウントのGoogle Driveに保存されます。アプリの設置先は、ご自身のGoogle Cloudです。

## 手順：まずGoogleアカウントを確認する

ことばメモを開いて、**「このGoogleアカウントで利用します」**と表示されている方は、ここから始めてください。

### 1. メールアドレスを確認する

画面の太字のメールアドレスが、**メモを保存したいGoogleアカウント**か確認します。PCとスマホでは、同じメールアドレスを選んでください。

Googleとの紐づけ（Google_ID）を確認するときは、このメールアドレスを目印にします。この画面でGoogle_IDを探したり、入力したりする必要はありません。初回設定で使う「クライアントID」は、アプリの認証設定に使う別のものです。

### 2. アカウントに合わせてボタンをクリックする

| 確認したこと | 次の操作 |
| --- | --- |
| 使いたいメールアドレスが表示されている | **「このアカウントで開始」**をクリックします。メモの画面が開きます。 |
| 別のメールアドレスが表示されている | **「別のアカウントを選ぶ」**をクリックします。Googleの画面で使いたいアカウントを選び、ことばメモに戻ってメールアドレスをもう一度確認します。 |
| メールアドレスがまだ表示されていない | **「Googleでログイン」**をクリックします。開いたブラウザで使いたいアカウントを選び、ことばメモのPC画面に戻ります。 |

「未送信データを削除します」と表示された場合は、いったんキャンセルしてください。現在のアカウントで開始し、「設定 → バックアップ」で保存してから、アカウントを変更します。

画面の「接続先」は、ことばメモを設置した場所のURLです。**Googleアカウントを選び直すときは「別のアカウントを選ぶ」を使います。**「接続先を変更」は、別の設置先へ切り替えるときに使います。詳しくは[接続先の変更手順](doc/user_guide.md#pcの接続先を変更)を確認してください。

### 3. メモの保存を確認する

1. 短いテスト用のメモを作り、保存します。
2. 「未送信：○件」や通信エラーの表示が残っていないか確認します。未送信の間は、変更がまだ端末にあります。表示が残る場合は、通信を確認して「同期を再確認」をクリックします。
3. スマホでも使う場合は、PCの「設定 → スマホでも使う」を開き、スマホのカメラでQRコードを読みます。
4. スマホでも同じGoogleアカウントでログインし、メールアドレスを確認して「このアカウントで開始」をタップします。
5. PCで保存したテスト用メモがスマホにも表示されるか確認します。

メールアドレスの表示は、利用するアカウントの確認です。保存やPC・スマホ間の同期は、上の手順で別に確認します。メモはGoogle Driveのアプリ専用領域に保存されるため、通常のDriveファイル一覧には表示されません。

## まだアカウント確認画面まで進めていない方

- **設置済みのURLがある方**：PCの初回設定ガイドで「設置済みのURLがある」をクリックして接続します。その後、上の「まずGoogleアカウントを確認する」へ進みます。
- **これから初めて設置する方**：PCの「初回設定ガイド」で「最初から準備する」をクリックします。Google Cloudへの設置が終わったら、Googleでログインし、上のアカウント確認へ進みます。

PC版の初回設定ガイドは、12画面を順番に進める案内です。「命令をコピー」「Googleの設定ページを開く」などのボタンで進められます。「ここで休む」で中断し、次回「続きから再開する」で続けられます。「図解マニュアル・印刷」で紙にもできます。詳しくは[初回設定ガイド](doc/guided_setup.md)を確認してください。

## 構成とアカウントの扱い

作者の公開URL・Googleプロジェクト・Supabaseに依存しない構成です。

- **PC**：専用のWindowsアプリをインストールし、自分の設置先URLを入力します。Googleログインは外部ブラウザで行います。
- **スマホ**：同じURLを開き、同じGoogleアカウントでログインします。PWAのホーム画面追加に対応します。
- **保存**：本人のGoogle Driveのアプリ専用領域。端末キャッシュは接続先・OAuthクライアント・アカウントごとに分離します。
- **Google認証**：Cloud側の認可コードフロー＋PKCE。秘密情報は自分のSecret Managerへ登録します。Googleの生のトークンはWeb画面へ返しません。
- **アカウント確認**：起動時にメールアドレス・接続先・保存先を表示し、「このアカウントで開始」を押すまでメモを読み込みません。
- **ログアウト**：端末のそのアカウントのキャッシュを削除します。未送信データは先にバックアップしてください。

## 開発・ビルド

Node.js 22以上を使います。

```sh
npm ci
npm test
npm run build
# .env.server.example を .env.server へコピーし、自分の設定を入力
npm start
# http://localhost:8080
```

OAuthのリダイレクトURIは開発時 `http://localhost:8080/auth/callback` です。SESSION_KEYは `.env.server.example` の生成コマンドで作成します。秘密情報をVITE_変数へ入れないでください。

Viteで編集する場合は、サーバーを8080で動かし、APP_ORIGINとOAuthリダイレクトURIを `http://localhost:5173` に変更して `npm run dev` を実行します。APIと認証は8080へ転送されます。

Windowsアプリの依存はWeb版と分けています。

```sh
npm install --prefix desktop
npm run desktop
# Windows上で実行
npm run dist:windows
# release/kotoba-memo-setup.exe
```

GitHub Actionsの「Build Windows setup.exe」でも生成できます。セットアップはElectronアプリを同梱し、専用の保存領域と接続設定を持ちます。固定URLを開く旧NSISスクリプトとGitHub Pagesへの自動公開は削除しました。

Cloud用の[Dockerfile](Dockerfile)と[設置スクリプト](deployment/deploy.sh)を収録しています。設置には本人のGoogle Cloud設定・課金設定が必要です。コード署名、実際のGoogle OAuth、Windowsでのインストール、PC・スマホ間の実機同期は[検証記録](doc/verification.md)を確認してください。
